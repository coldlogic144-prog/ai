Deploying to GitHub Pages

This web application is 100% static client-side HTML, CSS, and JavaScript. No servers, node backends, or external APIs required.

  1. 1. Push repository to GitHub: git init && git add . && git commit -m "Deploy digit classifier" && git branch -M main git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git git push -u origin main
  2. 2. Enable GitHub Pages:

    Go to your GitHub repository → Settings → Pages (sidebar).

  3. 3. Select Branch:

    Under Build and deployment > Branch, select main and folder / (root), then click Save.

  4. 4. Ready in ~60 Seconds:

    Your classifier will be live at: https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/
