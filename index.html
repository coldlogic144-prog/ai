How to Host on GitHub Pages

This web application is 100% static client-side HTML, CSS, and JavaScript. No servers, node backends, or Firebase required!

  1. Push your code to GitHub: git init && git add . && git commit -m "Add ML Web Interface" && git branch -M main git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git git push -u origin main
  2. Enable GitHub Pages in Repository Settings:

    Go to your repository on GitHub → Settings → Pages (on left sidebar).

  3. Select Branch and Folder:

    Under Build and deployment > Branch, select main and folder / (root), then click Save.

  4. Done!

    Within ~60 seconds, your site will be live at: https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/
